Qinyi Printing はジグソーパズル、3D紙パズル、ボードゲーム、カードゲーム、印刷ギフト包装を製造しています。以下の範囲は、既存のジグソー金型とプロジェクト固有のオプションを分けており、バイヤーは見積もり依頼前に概要を確認できます。

文書化された完成品サイズ範囲：14～91.3 cm

通常開始数量：通常ジグソーパズルは300セット*

製品ファミリー01

ジグソー＆アートパズル

既存の抜型フォーマットを使用して効率的に開始するか、エンジニアリングレビュー後にカスタムの輪郭とピースシステムを発注する。

24～56個

幼児学習＆形状セット

文書化されたフォーマットには、14 x 14、20 x 14、21 x 29.7、26 x 18、30 x 14、35 x 25 cmが含まれます。大ピース形状と年齢区分は、対象市場から確認されます。

100～300個

教育、ギフト、プロモーション

既存の例は20 x 20～49 x 36 cmに及び、正方形、長方形、形状オプションがあります。48ピースの91.3 x 61.3 cmフロアパズルフォーマットも文書化されています。

500～1000個

アート、リテール、コレクターズエディション

既存の500ピースフォーマットは40 x 58～75 x 55 cmに及びます。文書化された1000ピースフォーマットには、正方形、長方形、67.5 cmの円形エディションが含まれます。

ボードゲーム＆カード。

梱包

製品ファミリー04

印刷ギフト包装

当社の対応範囲は、カラーボックス、ギフトボックス、折り畳みカートン、紙袋、タグ、説明書を含みます。構造、ボードまたは紙の方向、インサート、開閉方法、印刷仕上げ、カートン包装は、包装される製品に合わせて調整されます。
